## Automatic task/request messages

Production now creates one portal message (not a duplicate notification + chat thread) for:

- task creation for an owner;
- task field changes;
- owner transfer (old owner and new owner receive the appropriate message);
- task deletion;
- request result: approved, rejected, needs revision, or cancelled.

The old `delivery_system_conversation` trigger is removed, active system-recipient chat threads are disabled, and `chat_conversation_list()` excludes system-recipient threads.
